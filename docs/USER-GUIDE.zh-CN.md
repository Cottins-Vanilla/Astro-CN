# Astro CN 使用指南

## 创建知识库

安装并打开应用后，选择一个用于长期保存笔记的文件夹。程序会在其中创建 .astro 子目录。建议把知识库放在文档或工作目录中，避免放在安装目录和临时目录里。

## 写第一篇笔记

在左侧新建笔记，填写标题并输入正文。正文自动保存，无需手动另存为。可以按“问题现象 → 原因分析 → 解决步骤 → 示例代码 → 相关知识”的顺序整理 Bug 复盘。

编辑方式有三种：

- **编辑**：隐藏常见 Markdown 标记，使用工具栏或快捷键整理内容。
- **预览**：阅读排版后的完整内容。
- **源码**：直接查看、修改 Markdown 原文，需要调整链接地址或表格时尤其方便。

复制来的富文本会尽量转换为 Markdown；特别复杂的网页样式可能需要在源码模式中手动整理。代码块内保留纯代码，不把其中的 Markdown 符号当成排版指令。

## 代码与错题

选择代码语言后点击插入代码，输入或粘贴程序。也可以从 VS Code 复制代码后粘贴。常见语言包括 Java、JavaScript、TypeScript、Python、C++、C#、Go、Rust、SQL、HTML、CSS、JSON 和 Shell。

建议同时记录代码的输入条件、错误输出和正确输出，以便日后复习。程序支持笔记之间的关联；本版不提供点击笔记链接直接打开电脑任意本地文件的功能。

## 文件夹分类

左侧的“…”菜单提供创建、改名、移动和删除操作。文件夹可以放进其他文件夹，其子目录和笔记一起移动。

拖到文件夹行的中间高亮区域是移入；拖到条目上下沿出现的插入线可调整位置。拖到“最外层”可将子目录或笔记移到根层级。也可以使用菜单操作，避免拖动不准确。

删除分类时仔细阅读对话框：默认保留里面的笔记，只有明确选择删除内容才会删除笔记。不能把文件夹移动到自己或自己的子目录中。

每次重新打开应用后文件夹默认收起。同一次使用中的展开状态会保留。

## 关联与星图

点击星星打开笔记；按住 Shift，从一颗星拖到另一颗星建立关联。正文中的双向链接同样会出现在图谱中。

修改笔记标题后，星图会在保存完成后更新；已有指向该笔记的引用会一起调整，笔记的身份、正文和结构关联保留。

2D 模式下可点击“自动整理”，让星星重新分散。节点和标题会尽量避让，但并不能消除所有连线交叉。3D 模式、星座排列和悬停高亮适合从不同角度查看知识关系。

## 配置智能助手

在设置中选择服务商，填写自己服务的接口地址、模型和 API 密钥，再进行连接测试。DeepSeek 提供快捷配置；其他兼容服务需要使用其实际支持的地址和模型。

助手面板展示当前模型及配置状态。回答下方的“插入当前笔记”会把内容追加到当前笔记末尾。使用前确认当前打开的是目标笔记。

配置完整不等于服务可用：网络、额度、接口权限及模型名称仍会影响请求。不要把服务返回的错误文本或包含密钥的截图公开上传。

## 备份和迁移

使用“导出知识库备份”，或在应用停止编辑后复制整个知识库文件夹。只复制 notes 会遗漏手动建立的图谱关联和知识库设置。

应用配置保存在 Windows 的 %APPDATA%/Astro-Chinese。API 配置可能包含在知识库设置中；共享、同步或提交 Git 前先清除密钥。

卸载应用通常只删除程序文件。你的外部知识库应单独管理；为避免误删，不建议把知识库建在安装目录内。
