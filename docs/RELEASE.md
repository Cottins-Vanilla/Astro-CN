# 发布说明与检查流程

## 本次拟发布信息

- GitHub 仓库：Cottins-Vanilla/Astro-CN
- 可见性：公开
- 版本标签：v0.2.0
- Release 标题：Astro CN 0.2.0 · 中文增强版
- 源码分支：main
- 安装包：Astro-CN-0.2.0-windows-x64-setup.exe
- 校验文件：SHA256SUMS.txt
- 可附加：Astro-CN-0.2.0-source.zip（GitHub 同时会生成标签源码归档）

## 发布内容

发布正文应包含：项目来源、主要功能、系统要求、安装与升级方法、本地数据位置、AI 配置与隐私说明、已知限制、测试结果和许可证说明。正文草稿见 RELEASE-NOTES.md。

## 本地检查

1. 完成构建、类型检查、测试与个人路径扫描。
2. 确认许可证、第三方声明、依赖许可和演示截图完整。
3. 使用隔离安装目录与测试知识库检查安装、启动和卸载。
4. 核对待提交列表不含真实知识库、应用配置、密钥、依赖或安装产物。
5. 提交源码，确认工作区干净；按最终产物生成 SHA-256。
6. 请项目所有者确认仓库名称、公开范围和最终附件后再发布。

不要把安装包直接加入 Git 历史。创建 Release 后，检查页面、版本标签、安装包下载地址和附件校验和。
