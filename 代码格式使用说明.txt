Astro 本地中文版 0.1.1

双击 Astro中文版.exe 即可使用，无需安装。请保留整个文件夹。
第一次启动时，选择一个用于保存知识库的文件夹。

常用操作
点击星星：打开笔记。
按住 Shift 从一颗星拖到另一颗星：建立关联。
Ctrl+K：搜索操作和笔记。
Ctrl+B：展开或收起笔记列表。
Ctrl+G：切换星座排列。

汉化范围
菜单、设置、操作提示、示例笔记、内置插件、星座名称和常见错误信息。
品牌名、模型名称、网址、文件路径、代码及第三方服务返回的信息可能保留原文。
本地汉化版不是原作者的官方中文发行版。

笔记保存在你选择的文件夹中，配置单独保存在 AppData\Roaming\Astro-Chinese。
用“导出知识库备份”保存副本。
原项目：https://github.com/Solen-AI-org/Astro

新增：代码格式（2026-11-02）
在笔记上方选择代码语言，点击“插入代码”，再输入或粘贴代码。
也可以先选中已有内容，再点击“插入代码”将其转为代码块。
点击“预览”可以查看语法高亮和行号，并用“复制代码”复制纯代码。
支持 Java、JavaScript、TypeScript、Python、C++、C#、Go、Rust、SQL、HTML、CSS、JSON、Shell 等。
代码随笔记保存在原来的知识库中，保持 Markdown 文件兼容性。

代码配色更新（2026-11-02）
编辑和预览使用同一套代码高亮规则。
深色界面使用柔和的浅紫、浅绿和米色；浅色界面自动使用较深的对应颜色。
注释、行号、标点和代码背景已分别调整，切换界面主题时自动适配。

代码显示更新（2026-11-02）
编辑时自动隐藏代码块前后的格式标记，只显示代码和淡色语言标签。
预览、语法高亮和复制代码功能保持可用。笔记文件仍使用标准 Markdown 格式保存。

文件夹分类更新（2026-11-02）
点击左侧“笔记”旁的文件夹加号，输入名称并创建。
可以用“Java/错题”创建多级文件夹。
把笔记拖到文件夹即可归类，也可以点击笔记右侧的“…”选择“移动到文件夹”。
选择文件夹后，再点 +，新笔记会直接创建在该文件夹中。
“最外层”显示还没有放入文件夹的笔记。分类会随知识库保存。
同名笔记移入同一文件夹时会自动区分文件名，不会覆盖已有正文。

分类管理更新（2026-11-03）
点击文件夹右侧的“…”或右键点击文件夹，可以重命名、新建子文件夹或删除文件夹。
重命名文件夹时，子文件夹和里面的笔记会一起更新位置。
删除文件夹默认保留里面的全部笔记，并移到“最外层”。
如需连笔记一起删除，必须在确认窗口中勾选“同时删除”，删除后无法恢复。
点击笔记右侧的“…”或右键点击笔记，可以重命名、移动到文件夹或删除笔记。
重名、无效名称和操作失败会显示提示，分类会随知识库保存。


DeepSeek 智能助手更新（2026-11-03）
重新打开软件，在“设置 → 智能助手”中将“模型服务”选择为 DeepSeek。
官方接口地址和模型会自动填入，只需填写自己在 DeepSeek 开放平台申请的 API 密钥。
点击“测试连接”，显示成功后点击“保存设置”，再返回智能助手输入问题。
默认使用 Flash，可选 Pro，也能手动填写其他模型名称；“深入思考”适合复杂代码和排错。
密钥可在 https://platform.deepseek.com/ 申请；网页版登录密码不能替代 API 密钥。
接口和模型以 DeepSeek 官方文档为准：https://api-docs.deepseek.com/zh-cn/
连接测试会发送一条简短消息，可取消测试。密钥无效、余额不足、请求过频等情况会显示中文提示。
本次接入已通过模拟接口和独立桌面验证；真实账号是否可用需填入自己的有效密钥后测试。


侧栏与动画更新（2026-11-03）
侧栏调整了宽度、文字大小、行高和缩进，减少计数与边框干扰；文件夹展开和收起采用平滑动画。
文件夹使用打开与关闭的图标区分状态，操作菜单浮动显示。菜单、新建窗口和预览切换增加轻微动画。


智能助手模型信息更新（2026-11-03）
智能助手顶部显示当前服务、完整模型名称、深入思考状态，以及配置/回复状态。
点击模型信息卡片即可修改模型设置。每条回答下方保留当时选择的模型名称，切换模型后仍可区分旧回答。
“配置已填写”表示已具备请求所需设置，实际连接情况可在模型设置中点击“测试连接”确认。


文件夹启动收起更新（2026-11-03）
每次启动软件或重新打开知识库时，所有文件夹（包括子文件夹）默认收起，不再恢复上次的展开记录。
本次使用过程中，可以正常展开和收起；切换笔记或隐藏侧栏不会重置本次状态。


本地文件打开功能已移除（2026-11-03）
已移除“插入文件链接”、关联文件按钮，以及点击链接打开电脑文件的功能。
已有笔记正文和路径文字保持原样，旧文件链接不再打开本地文件。


智能助手插入笔记修复（2026-11-03）
点击回复下方的“插入当前笔记”，会将这条回复追加到当前笔记末尾，并显示“已插入笔记末尾”。
编辑区和预览会立即同步，代码块保留原格式；继续编辑不会覆盖刚插入的回复。
可用 Ctrl+Z 单独撤销插入，内容会自动保存。切换笔记后，按钮会插入当前打开的笔记。

Markdown 编辑更新（2026-11-04）
笔记支持 Markdown 排版，编辑时可看到标题大小、加粗、斜体、引用和代码样式。
上方新增“标题、加粗、斜体、列表、编号、引用、行内代码、链接”按钮，选中文字后点击即可设置。
Ctrl+B 为加粗，Ctrl+I 为斜体；格式操作可以使用 Ctrl+Z 撤销。
点击“预览”查看完整阅读效果，包括表格、任务清单、列表、分隔线和代码高亮；点击“编辑”继续修改。
正文会自动保存。原有文字保留；普通段落如需变为标题或列表，可直接使用上方格式按钮。


侧栏同级移动更新（2026-11-04）
文件夹和笔记在同一层级可以混合排列，最外层笔记直接显示在文件夹之间。
拖动文件夹或笔记到同层另一项的上沿或下沿，出现插入线后松开，即可调整前后顺序。
也可以点击右侧“…”或右键，在菜单中选择“上移 / 下移”。子文件夹内部同样支持。
将文件夹或笔记拖到文件夹行的中间可移入；拖到下方“最外层”可移出。
排列顺序随知识库保存，改名和重启后保持；每次重启时文件夹仍默认收起。
搜索时显示匹配结果，清空搜索后可继续调整顺序。

保留粘贴格式与隐藏标记更新（2026-11-04）
“编辑”现在直接显示常见 Markdown 排版，标题、加粗、斜体、删除线等标记默认隐藏，不再一直显示 ## 或 **。
从网页或聊天复制内容后，直接 Ctrl+V，可保留常见标题、加粗、斜体、列表、引用、网页链接、代码和表格。
原生 Markdown 文本也会自动显示排版；代码中的井号、星号、缩进和空行保留原样。
有任务清单时，可以直接点击复选框。表格直接显示，点击“编辑表格”可进入源码修改。
需要查看或修改 Markdown 标记、链接地址时，点击“源码”；完成后点击“编辑”即可恢复排版视图。
“预览”用于完整阅读。模式切换不会修改正文，粘贴和格式操作可用 Ctrl+Z 撤销，内容仍自动保存。
保留的是 Markdown 支持的常见格式，原网页的自定义字体、颜色和复杂页面布局不会照搬。
已有 Markdown 笔记直接使用新显示效果；原有笔记正文不会被批量改写。


文件夹跨层级移动更新（2026-11-04）
文件夹可以拖入其他文件夹，里面的全部子文件夹、笔记和空目录会一起移动，内部排列保持。
拖到目标文件夹行的中间，看到高亮后松开，即可移入；拖到行的上沿或下沿出现插入线时，可调整所在层级和顺序。
把子文件夹拖到下方“最外层”即可整棵移出，不需要逐篇移动笔记。
点击文件夹“…”或右键，可以选择“移动到文件夹”；子文件夹还提供“移到上一层”。
移动目标中不会列出自己和自己的子文件夹；目标位置已有同名文件夹时会提示先重命名，不会自动合并或覆盖。
移动失败时会尝试将已经移动的笔记移回原处，并显示失败原因。
移动结果随知识库保存，重启后保留；重启时文件夹仍默认收起。

2D 星图防拥挤更新（2026-11-04）
2D 星图改为真正的平面布局，节点在平面内互相避让，并增加节点间距，减少叠在一起的情况。
首次打开或切换到 2D 时，布局稳定后会平滑适配视图；新增笔记或关联后自动重新整理，无需反复刷新窗口。
2D 星图顶部新增“自动整理”按钮，可以在当前视角重新分散节点，不重置手动缩放和平移。
标题会避让星星和其他标题，空间不足时暂时省略部分标题；悬停星星仍可查看名称。
连线恢复原有颜色和透明度；悬停节点时仍突出它的关联线。
缩小查看全图时，星星仍保留基本可见大小。布局稳定后停止计算，避免一直晃动。
布局调整只影响显示，不会删除、改写笔记或取消关联；关联很多时仍可能出现交叉连线。


连线颜色恢复（2026-11-04）
已撤回上次新增的 2D 连线减淡效果，恢复原有颜色和透明度。节点防重叠、文字避让及自动整理继续生效。

笔记重命名修复（2026-11-05）
从星图打开笔记后，修改标题仍是同一篇笔记，星图会自动更新名称。
指向这篇笔记的旧标题链接会一起更新，保留原有连线、显示别名和标题内的段落定位。
连续输入标题或保存较慢时，也会等待标题与引用全部保存后更新星图，避免旧标题变成待创建的新笔记。
文件夹内有同名笔记时，只更新实际指向这篇笔记的引用；正文、代码和笔记位置保留。
